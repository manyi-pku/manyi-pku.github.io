Euler-Poinsot motion

惯量椭球与角动量椭球

椭球空间橙色：Poinsot，蓝色：Binet
定点转动无重力自由刚体

精确 n=e2 是不稳定平衡，会一直保持；稍微调节 theta_n, phi_n 可加入扰动并演示翻滚。

动能：J1 omega1^2 + J2 omega2^2 + J3 omega3^2 = 2T

角动量：J1^2 omega1^2 + J2^2 omega2^2 + J3^2 omega3^2 = G^2

初始角速度：omega(t=0)=omega0 n

系统动能：T = 1/2 Jn omega0^2，Jn = J1 n1^2 + J2 n2^2 + J3 n3^2

角动量：G = omega0 J·n，G^2 = omega0^2 Kn

2T = 1，Je = Kn/Jn = (J1^2 n1^2 + J2^2 n2^2 + J3^2 n3^2)/(J1 n1^2 + J2 n2^2 + J3 n3^2)，G^2 = Je

惯量椭球（Poinsot）：omega1^2/(1/J1) + omega2^2/(1/J2) + omega3^2/(1/J3) = 1

角动量椭球（Binet）：omega1^2/(Je/J1^2) + omega2^2/(Je/J2^2) + omega3^2/(Je/J3^2) = 1
